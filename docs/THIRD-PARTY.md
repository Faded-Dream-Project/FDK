# THIRD-PARTY — components, data, and provenance (1.1.0)

Everything FDK builds on, links, loads, vendors, or reads, with its
license and source. FDK itself is proprietary (LICENSE, the FDK
Proprietary License v1.0); the policy that governs additions is
docs/licensing-policy.md. The rule for this file: every row is
something a distribution might ask about; if it is not listed here,
FDK does not depend on it.

## Link-time dependencies (the .so's NEEDED set)

| component | license | source | why |
|-----------|---------|--------|-----|
| libc (glibc/musl), libm, libdl | LGPL-2.1-or-later / MIT (musl) | system | the C runtime; libdl is a no-op stub on glibc ≥ 2.34 |
| libX11, libXext | MIT | system | the X11 backend (protocol via Xlib) |
| libwayland-client | MIT | system (optional; builds without it) | the Wayland backend |
| libxkbcommon | MIT | system (optional, with Wayland) | keymap translation on Wayland |
| libz | zlib | system | PNG encode/decode |
| libpthread | MIT | system | merged into glibc ≥ 2.34; explicit on older toolchains |

No D-Bus library is linked (D-001): the client in src/dbus/ is
FDK's own code from the public specification.

| libGL/libGLX | MIT / SGI-B-1.1-ish (per-driver) | libGL.so.1 | X11 GPU lane off; software rendering (the default posture) |

## Protocol definitions FDK speaks (implemented from public specifications)

Implemented from the public freedesktop.org specifications in FDK's
own words and code — no code, tables, or text copied from GPL/
LGPL/AGPL projects (the licensing-policy rule):

- The D-Bus wire protocol and SASL profile (src/dbus/). Byte-level
  correctness was validated against the reference implementation's
  observable output (captured socket writes) — behavior, not code.
- wlr-layer-shell v4 (fdk-shell, from the vendored XML).
- xdg-shell, xdg-decoration, viewporter, fractional-scale-v1,
  primary-selection-unstable-v1, cursor-shape-v1 (Wayland scanner
  bindings generated from the wayland protocol XMLs).
- EWMH/_NET_WM hints, ICCCM, XDND (X11, from the published specs).
- XSETTINGS (src/platform/x11/x11_xsettings.c).
- StatusNotifierItem/Watcher, org.freedesktop.Notifications,
  org.freedesktop.portal.Settings, org.freedesktop.ScreenSaver,
  AT-SPI2 (planned on the D-Bus foundation; same posture).

## Bundled data

| the narrator's message catalog | FDK Proprietary (ours) | i18n data |
| fonts, emoji, cursors, icon themes | — (none bundled) | — |

Unicode data (CLDR plurals, East-Asian widths as used) is compiled
into FDK's own tables from the public Unicode data files' values;
the UCD's license (unicode.org/terms, permissive) permits this and
the tables are regenerated by our own tooling (tools/).
